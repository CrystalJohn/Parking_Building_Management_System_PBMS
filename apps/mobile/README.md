# @parking/mobile

> **Phase 2 Placeholder** — React Native mobile app for Drivers.

This package is a placeholder for the Phase 2 mobile application. It will be implemented after the Phase 1 web application is complete.

## Planned Features

- Driver login
- View slot availability by floor/zone
- Display QR code for check-out
- Make/cancel reservations
- View parking history

## Tech Stack (planned)

- React Native (latest)
- React Navigation
- Axios
- Secure storage for JWT

See the main [design document](../../.kiro/specs/parking-building-management/design.md) for full details.
